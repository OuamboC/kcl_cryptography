IND-CPA Game: You Are the Adversary

The challenger flips a hidden bit b and encrypts m_b. You send pairs (m0, m1) of equal length and get ciphertexts back. Guess b. Try both schemes.
Press "New round" first.
Auto-attack: run 2000 rounds with the repeat strategy

Strategy: query (x, x) then (x, y). If both ciphertexts are equal, guess 0, otherwise guess 1.

Insight: with a fresh key per message the attacker wins about 50 percent (advantage near 0). With a reused key, encryption is deterministic, the attacker wins 100 percent (advantage 1). Advantage = 2 x |Pr[b' = b] - 1/2|.
