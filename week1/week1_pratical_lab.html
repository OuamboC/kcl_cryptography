2. Calculation lab

A. Text → hex → binary → XOR → base64

ASCII text only, up to 60 characters. Key is one byte in hex (00 to ff).

Try the full lab string "Karma police, arrest this man, he talks in maths" with key 01. The base64 should match the lab's sanity check.

B. Single-byte XOR breaker

Score = 2 points per space + 1 per letter, only for fully printable results. Real attacks use full letter-frequency tables (a later topic).

C. RBAC composer: UA ⋄ PA

Formula: AC = {(S,P) | there exists R with (S,R) in UA and (R,P) in PA}. Try changing Dev to Admin and watch the pair count change.

D. Search-space and brute-force time

Search space = choices per position ^ positions. Average attacker success needs half of it.

E. Calculation drills (paper first)

  1. 0x4B XOR 0x01 = ?
  2. 0xA5 XOR 0x5A = ?
  3. What is x XOR x? What is x XOR 0x00?
  4. m1 = 0x41, m2 = 0x42, key k = 0x7F reused. Find c1, c2, then c1 XOR c2. Compare with m1 XOR m2.
  5. A 48-byte ciphertext is base64-encoded. How many characters long is the result?
  6. If the anonymity set has N equally likely senders and you know nothing else, what is the chance of guessing the sender? Give N = 4 and N = 1000.
Check my answers
  1. 0x4A (01001011 XOR 00000001 = 01001010).
  2. 0xFF (10100101 XOR 01011010 = 11111111).
  3. x XOR x = 0x00, and x XOR 0x00 = x. This is why XOR with the key twice decrypts.
  4. c1 = 0x41 XOR 0x7F = 0x3E. c2 = 0x42 XOR 0x7F = 0x3D. c1 XOR c2 = 0x03 = m1 XOR m2. The key cancels, so reusing a key leaks the relationship between plaintexts (the two-time pad flaw).
  5. Every 3 bytes become 4 characters: 48 / 3 × 4 = 64 characters.
  6. 1/N: 25% for N = 4, and 0.1% for N = 1000. This assumes a uniform guess; real attackers use timing and traffic analysis to beat it (Lecture 1.2, Slide 10).

4. Mini project: Vault Guard

What you build: a tiny secured file vault in Python 3 (standard library only, about 100 lines). Users log in, a single gate decides every access, and every decision lands in a tamper-evident audit log.

Why: it turns this week's words (authentication, authorisation, DAC, RBAC, reference monitor, NEAT, accountability) into code you can attack.

"""Vault Guard - Week 1 mini project (reference solution). Python 3, standard library only."""
import hashlib
import hmac
import json
import os
import time

# ---------- Milestone 1: identification + authentication ----------
USERS = {}  # username -> (salt, password_hash)

def _hash(password, salt):
    return hashlib.pbkdf2_hmac("sha256", password.encode(), salt, 200_000)

def register(username, password):
    salt = os.urandom(16)                      # fresh random salt per user
    USERS[username] = (salt, _hash(password, salt))

def authenticate(username, password):
    if username not in USERS:
        return False
    salt, stored = USERS[username]
    return hmac.compare_digest(stored, _hash(password, salt))

# ---------- Milestone 2: authorisation (DAC matrix + RBAC) ----------
OBJECTS = {"notes.txt": "draft plot twist", "logs.txt": "server log data"}
OWNER = {"notes.txt": "ana", "logs.txt": "ben"}
ACM = {("ana", "notes.txt"): {"read", "write"}}          # DAC: owner-granted
UA = {"ana": "analyst", "ben": "admin", "dev": "guest"}   # RBAC: subject -> role
PA = {                                                    # RBAC: role -> (object, privilege)
    "guest":   {("notes.txt", "read")},
    "analyst": {("notes.txt", "read"), ("logs.txt", "read")},
    "admin":   {("logs.txt", "read"), ("logs.txt", "write")},
}

def allowed(subject, obj, priv):
    if priv in ACM.get((subject, obj), set()):            # DAC rule
        return True
    role = UA.get(subject)
    return role is not None and (obj, priv) in PA.get(role, set())   # RBAC rule; default deny

def grant(owner, subject, obj, priv):
    """Only the owner may change the matrix (DAC)."""
    if OWNER.get(obj) != owner:
        return False
    ACM.setdefault((subject, obj), set()).add(priv)
    return True

# ---------- Milestone 4: tamper-evident audit log (accountability) ----------
LOG = []
GENESIS = "0" * 64

def _entry_hash(prev, event):
    body = json.dumps(event, sort_keys=True)
    return hashlib.sha256((prev + body).encode()).hexdigest()

def log(event):
    prev = LOG[-1]["hash"] if LOG else GENESIS
    LOG.append({"event": event, "prev": prev, "hash": _entry_hash(prev, event)})

def verify_log():
    prev = GENESIS
    for e in LOG:
        if e["prev"] != prev or e["hash"] != _entry_hash(prev, e["event"]):
            return False
        prev = e["hash"]
    return True

# ---------- Milestone 3: the reference monitor (single gate) ----------
def request(username, password, obj, priv):
    if not authenticate(username, password):
        decision = "DENY:auth"
    elif obj not in OBJECTS:
        decision = "DENY:no-such-object"
    elif allowed(username, obj, priv):
        decision = "ALLOW"
    else:
        decision = "DENY:policy"
    log({"t": round(time.time(), 2), "who": username, "obj": obj, "priv": priv, "decision": decision})
    return decision == "ALLOW"

def read(username, password, obj):
    return OBJECTS[obj] if request(username, password, obj, "read") else None

def write(username, password, obj, data):
    if request(username, password, obj, "write"):
        OBJECTS[obj] = data
        return True
    return False

# ---------- Milestone 5: attack day ----------
def selftest():
    register("ana", "correct horse"); register("ben", "battery staple"); register("dev", "hunter2")
    assert read("ana", "correct horse", "notes.txt") == "draft plot twist"   # allowed
    assert read("ana", "WRONG", "notes.txt") is None                         # authentication fails
    assert read("dev", "hunter2", "logs.txt") is None                        # guest cannot read logs
    assert not write("dev", "hunter2", "notes.txt", "x")                     # guest cannot write
    assert not grant("dev", "dev", "notes.txt", "write")                     # non-owner cannot edit matrix
    assert grant("ana", "dev", "notes.txt", "write")                         # owner can
    assert write("dev", "hunter2", "notes.txt", "dev edit")
    assert verify_log()                                                      # log intact
    LOG[1]["event"]["decision"] = "ALLOW"                                    # attacker rewrites history
    assert not verify_log()                                                  # tampering detected
    print("All Vault Guard tests passed.")

if __name__ == "__main__":
    selftest()

What Vault Guard does NOT give you

  • Non-repudiation. A hash chain proves order and detects edits, but whoever holds the log can rebuild the whole chain. Non-repudiation needs digital signatures (coming later).
  • Confidentiality at rest. XOR obfuscation is not encryption in any useful sense. Real encryption (block ciphers, authenticated encryption) replaces it in later weeks.
  • Anonymity. The log names every user. Confidentiality and anonymity are different properties.
